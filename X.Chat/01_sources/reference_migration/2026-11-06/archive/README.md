# Frozen pre-move navigation

Tags: #project/trident #doc/index

`pre_move_navigation/notes/` and `pre_move_navigation/workspace/` preserve original navigation bytes before the reference move. They are historical sources, not active routes. The parent `navigation_before_manifest.json` records hashes; the live notes/root maps give current locations.
