# Local repository alias

- `Papers` is a local directory symlink to the existing `Paper_and_Presentations` parent outside Box.
- Notes use its stable path inside the vault rather than absolute `/Users/...` links.
- This is the live working tree, not a copied source collection. Scripts editing notes must not recurse through the alias.
- Box does not synchronize the symlink or its target. Recreate the same alias on another computer with its actual local repository path.
