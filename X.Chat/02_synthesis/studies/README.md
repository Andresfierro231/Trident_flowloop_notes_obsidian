# Standalone continuing studies

Use this only when a substantive evidence investigation needs its own durable
bundle; small synthesis edits stay in their maintained topic notes.

- Initial home: YYYY/MM/DD/topic/ with one README and report_study.json.
- Expansions: original study/YYYY-MM-DD/expansion/; keep issued sources unchanged.
- At three distinct recorded work dates, promote to creation YYYY/MM/topic/.
- Update the canonical project map, affected indexes and old/new/hash move map.
- Use the study template; record owner, purpose, actual work_dates and evidence
  limits. Scientific code/data and raw assets remain with their existing owner.
