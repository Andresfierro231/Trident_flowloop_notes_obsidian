# Original-source verification

Use the current owner map and citation policy. Search existing source records
before repeating literature discovery.

- Open the original paper, thesis, manufacturer document or implementation that
  supports the claim. Record exact title, author, date and equation/page/section.
  A search snippet, product name or bibliography entry is a discovery pointer.
- Compare the actual coefficients, temperature convention, units, composition,
  range and material identity. Separate exact matches, rounding, alternative
  laws, product context and unresolved provenance.
- For author-defined laws, cite the thesis or source definition that actually
  contains them. Do not attach a plausible publication to different coefficients.
  An unsuccessful search does not prove a correlation was invented.
- For the proposal, internal Trident notes and candidate-library manifests stay
  in provenance records, not its scholarly bibliography. Preserve explicit
  unresolved status when the original fit source is unavailable.
- Maintain the existing source record and citation keys. After citation-order
  changes, let the owner's bibliography tool number references and align its
  Markdown companion. Do not silently change numerical laws while fixing citations.

Use text/numeric inspection first. Source images follow the owning visual-access
rule. Keep missing-source questions specific; continue independent verified work.
