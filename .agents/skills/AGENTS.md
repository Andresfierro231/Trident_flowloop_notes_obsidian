# Skill-pack maintenance

This notes-owned pack supports existing project instructions. For edits here,
read `_support/README.md`; preserve narrow triggers and source provenance.
Run its offline catalog check and smoke tests after changes. Regenerate the
catalog from metadata rather than maintaining two lists. Never import an entire
upstream pack, execute its installer or add a model call as a routing shortcut.
Routine agents outside this directory need only the selected skill.
