Andrew,

Attached is a Claude-created description of code to write that can be used for the steady state.    

An “experiment” is a steady-state condition with a fixed heater power and known ambient temperature, with measured temperatures at 18 locations (PTC 1-6 and STC 1-12).  

Note, I didn’t see a simplified pic of the VCU loop like you had of the A&M one with the TC locations clearly defined.  I also didn’t see the luna fiber info in the VCU data - or maybe I was looking in the wrong place.

The forward problem is:
given the data (thermal resistances between all nodes)
the input (ambient temp and heater power)
compute the temperature at all measured locations for the experiment.

The inverse problem is:
The data from one experiment is: temperature at PTC 1-6 and STC 1-12, heater power, and ambient temp.
Given: data from many experiments
Calibrate the thermal resistances between all nodes

If:
There is no flow, the thermal conductivity is not dependent on temperature, and IF there is no radiative/convective heat transfer from the insulation to the environment,
then the problem is linear 

The assumptions:
If you start with a reasonable thermal resistance, the calibration (inverse problem) will be much easier.
So if you have (approximate) details on material properties, its not bad to include it in the thermal resistance and only calibrate a “correction” to that.
If you start calibrating with the assumption that it is linear, 
Then the calibration will be easy and require little data
Then if you allow for non-linearity, it will only tweak the linear solution to pick up the small nonlinearities much easier.

You can give this to AI and see what it can do to write the code, or you can try writing it yourself, or some combination.   But know every line of what the code is doing and why.

After you get this working and we can compare with some of their data - maybe even provide some predictions, then we can work on the time-dependent ones that Nick proposed, which will add calibration of the heat capacities.






For posterity, my guidance to Claude was:
I need to create a mathematical description of a code that needs to be written by a student. The system we are modeling has a loop of pipes with 12 thermocouples at the centerline of the pipe (STC 1-12) and 6 thermocouples at the surface of the pipe (PTC 1-6). the pipe is insulated and there is a heater on a fluid inside the pipes. The only cooling from the system is to the room, which has an ambient temperature (Ambient). The system will start at room temperature and the heater will be turned on to a given power (Heater). Over time, the system will reach a steady-state with a temperature distribution through the fluid and temperature distribution on the pipe and insulation. The idea is to build a control volume model that includes at least the 12 fluid volumes (centered on the thermo couples) that are in a loop and at least 12 pipe volumes that are thin annuli (with 6 centered on the 6 PTCs) and at least 12 insulation volumes that are thick annuli. The mesh should be structured in (r,z), where z is the loop direction and r is radial. Because the PTCs may not be centered on the STCs, more than 12 mesh cells may be required in the radial direction. There should be a thermal resistance between each of the adjacent fluid volumes (remember it's a loop) and there should be thermal resistance between the fluid, the pipe, the insulation, and the ambient. There should be no thermal coupling between the different piping volumes and no thermal resistance between the insulation volumes. If the thermal resistances are known, the solver should take in a power and ambient temperature and solve for the temperatures in all cells. There should also be way to take data from many thermal equilibrium calculations and, with machine learning, solve for the thermal resistances.
