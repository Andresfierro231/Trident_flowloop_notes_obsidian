# Nick Luciano VCU experimental plan

Tags: #project/trident #doc/source #facility/vcu #domain/experiments

This user-supplied package replaces the former
`STNCL_Initial_Experiment_Plan.zip` with inspectable source files. The five
phase-specific TeX documents are the current plan; [`archive/`](archive)
retains the earlier combined draft. Checksums are registered in
[`../MANIFEST.sha256`](../MANIFEST.sha256).

The plan describes the VCU loop using Prop-30 glycol as its primary fluid.
The earlier repository description of mineral oil was superseded by the
user's 2026-09-14 clarification. The plan is evidence for experiment
intent and candidate instrumentation requirements, not controlling ACU or VCU
geometry and not a native DAQ channel map. The current text uses symbolic or
to-be-selected heater/cooler duties rather than supplying numerical
representative heater powers. It does not establish an accepted product,
mixture composition, or thermophysical-property correlation.

Images are retained as immutable source assets but were not opened or used for
the text-only review. Any dimensional inference from them is deferred.
