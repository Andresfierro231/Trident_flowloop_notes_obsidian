3.3.1
Convergence Classification
The ratio R = ε21/ε32 classifies the convergence behavior:
• 0 < R < 1: Monotonic convergence, where the changes in the solution shrink in
response to mesh refinement.
• R < 0: Oscillatory convergence, where the signs of the changes in the solution
alternate in response to mesh refinement.
• R > 1: Divergence, where the changes in the solution grow in response to mesh
refinement
